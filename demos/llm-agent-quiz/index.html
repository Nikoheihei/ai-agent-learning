基础模型 🧠
LLM
Large Language Model
通过海量文本预训练的概率模型，能够理解并生成人类语言，是一切 AI 应用的"大脑"基础。
关键原理
LLM 核心
📌 Next-token prediction：每次预测下一个最可能的词

📌 Transformer 架构：自注意力机制捕捉长距离依赖

📌 Temperature：控制输出随机性（0=确定，>1=创意）

📌 Context window：模型一次能"看到"的最大 token 数量

编排层 🔀
Workflow
确定性流程编排
将多个 LLM 调用或工具调用以固定顺序串联，执行路径由人类预先设计，可复现、可调试。
典型模式
Workflow 模式
🔗 Chain：依次调用，上一步输出是下一步输入

🔀 Router：根据分类结果走不同分支

⚡ Parallel：多任务并发执行，最后汇总

📋 Evaluator-optimizer：循环生成+评分直到达标
点击翻转 →
自主系统 🤖
Agent
自主决策 + 工具调用
LLM 作为"大脑"自主规划下一步行动，动态决定调用哪些工具、何时停止，循环直到目标达成。
核心循环
Agent Loop
1️⃣ 感知：接收环境状态与用户输入

2️⃣ 思考：LLM 推理并选择下一步行动

3️⃣ 行动：调用工具（搜索/代码/API）

4️⃣ 观察：获取工具结果，更新上下文

🔁 重复直到任务完成或达到最大步骤

能力扩展 🔧
Tool Use
工具调用 / Function Calling
LLM 生成结构化的函数调用请求，由外部系统执行，结果返回给 LLM 继续推理，突破纯文本限制。
常见工具类型
工具分类
🔍 信息检索：Web搜索、数据库查询、RAG

💻 代码执行：Python REPL、Shell、沙箱

🌐 外部服务：API调用、邮件、日历

💾 持久化：读写文件、记忆存储

状态管理 💾
Memory
上下文与记忆系统
Agent 如何在短期（对话）和长期（跨会话）维持状态信息，直接影响任务的连贯性与一致性。
四种记忆类型
记忆分层
🗂 In-context：当前窗口内的对话历史

📚 External DB：向量库/KV存储，跨会话持久

📝 Summarization：对长历史压缩摘要

🏋️ Fine-tuning：将记忆"烧录"进模型权重

Prompt
提示词工程
与 LLM 沟通的语言界面，包括 System Prompt 设定角色、User/Assistant 多轮对话，以及少样本示例。
高级技术
Prompting 技巧

🎭 Few-shot：给出示例让模型类比

④ 三者关系总览
🧠 LLM — 语言能力底层，提供理解与生成
↓ 封装 & 编排
🔀 Workflow — 固定流程，确定性高，适合生产稳定任务
↓ 赋予自主决策
🤖 Agent — 动态规划 + 工具调用，适合复杂开放任务
维度 🧠 LLM 🔀 Workflow 🤖 Agent
决策方式 Token 概率预测 人工预定路径 LLM 自主规划
可控性 中（受 prompt 影响） 高（确定性） 低（动态路径）
适用场景 文本生成/理解 结构化、可重复任务 开放式、多步骤任务
调试难度 难（黑盒） 易（流程清晰） 难（路径不可预测）
工具使用 否 可选（固定） 是（动态选择）
延迟 / 成本 低 中（多步） 高（多轮循环）
失败风险 幻觉输出 单点失败即中断 错误累积放大
